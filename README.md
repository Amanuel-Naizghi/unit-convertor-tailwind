# Unit Converter

A basic responsive unit conversion website built using HTML, TypeScript and Tailwind CSS.

## Features

- Weight conversion
- Distance conversion
- Temperature conversion
- Single-value conversion
- Array-value conversion
- Responsive design using Tailwind CSS

## Technologies

- HTML
- TypeScript / JavaScript
- Tailwind CSS
- Vercel for deployment
